The Best Movies According to Eduardo

My top 3 movies of all-time:

Interstellar

This is the best science fiction movie that has ever been created.
When you watch it the first time, it feels like a chaos, but once you understand it... it's awesome.

Project Hail Mary

It's a great movie that's funny and entertaining.
It has some sentimental parts but either some very funny ones!

The Matrix Trilogy

The Matrix trilogy is honestly incredible because the action and style are top-tier.
It builds such a cool, mind-bending world that keeps you hooked from the first movie to the last.
